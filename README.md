# موقع فرع المعلوماتية الطبية - المرحلة الرابعة

تصميم وتطوير: م. حمزة فلاح

## ماذا في المجلد
- `public/` الواجهة (صفحة واحدة + تطبيق قابل للتثبيت PWA + خدمة الإشعارات).
- `netlify/functions/api.mjs` الخادم وقاعدة البيانات (Netlify Blobs، مدمجة ولا تحتاج أي إعداد أو حساب إضافي).
- `netlify.toml` إعدادات النشر.

## النشر (الطريقة الأسهل: GitHub + Netlify)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي.
2. في Netlify: Add new site ← Import an existing project ← اختر المستودع ← Deploy.
   الإعدادات تُقرأ تلقائياً من `netlify.toml`، لا تغيّر شيئاً.
3. بعد دقيقة يعمل الموقع على رابط `xxxx.netlify.app`، ويمكنك تغيير الاسم من Site configuration.

## النشر بالأوامر (بديل)
```
npm i -g netlify-cli
netlify login
netlify deploy --prod
```
ملاحظة: السحب والإفلات (Drag & Drop) لا يشغّل الدوال، فلا تستخدمه لهذا المشروع.

## أول استخدام
1. افتح الموقع، انقر على الشعار 4 مرات بسرعة.
2. كلمة المرور الأولى `1234`. غيّرها فوراً من «لوحة الإدارة ← تغيير كلمة المرور».
   (اختيارياً: ضع متغير بيئة `ADMIN_PASSWORD` في Netlify ليكون هو كلمة المرور الأولى بدل 1234.)
3. أضف المواد (اسم المادة والدكتور) ثم المحاضرات ثم الملفات والواجبات والشريط المتحرك.

## الإشعارات
- **داخل الصفحة:** عند نزول تنبيه أو واجب أو ملف أو تغيير دكتور أو تحديث جدول، يظهر إشعار في أعلى الشاشة مع صوت منبه، ويختفي وحده بعد 9 ثوانٍ، وفيه زر «عرض» ينقل الطالب إلى المكان المقصود.
- **علامة «جديد»:** تظهر فوق الزر المقصود (الكورس أو الجدول أو المواد أو الواجبات) وفوق بطاقة التنبيهات، وتختفي عندما يفتح الطالب ذلك القسم. وتبقى محفوظة حتى لو أغلق الصفحة.
- **في الخلفية (الصفحة مغلقة):** يفعّل الطالب الإشعارات من الشريط الذي يظهر أعلى الصفحة أو من الإعدادات. يصله إشعار على الهاتف، والنقر عليه يفتح القسم المقصود.
- مفاتيح الإشعارات تُنشأ تلقائياً عند أول تشغيل.
- في الآيفون تعمل إشعارات الخلفية فقط بعد «إضافة إلى الشاشة الرئيسية» (iOS 16.4 فصاعداً).
- صوت الإشعار الخارجي هو صوت الهاتف الافتراضي (قيد من المتصفحات). صوت المنبه المخصص يعمل داخل الصفحة.

## العمل بدون إنترنت
- بعد أول زيارة بإنترنت، يحفظ الجهاز الصفحة نفسها والجدول والمواد والتنبيهات والواجبات وأخبار الشريط، وتظهر كلها عند فتح الصفحة بلا اتصال، ويظهر شريط «أنت بدون إنترنت» مع وقت آخر نسخة.
- صور الواجبات تُحفظ تلقائياً.
- ملفات المواد (PDF وWord وغيرها) تُحفظ بطلب الطالب: زر «حفظ بدون إنترنت» بجانب كل ملف، أو «حفظ كل الملفات» من الإعدادات (لتوفير بيانات الهاتف). الملف المحفوظ يكتب بجانبه «متاح بدون إنترنت».
- لا يمكن لأي أحد استلام التحديثات أو الإشعارات أو تعديل الأدمن بدون اتصال.
- عند تحديث الموقع بنسخة جديدة يأخذها الطالب في زيارته التالية بإنترنت.

## ميزات التحديث الأخير
- **ألوان الأزرار:** من لوحة الإدارة ← «ألوان الأزرار»: تتبدل بين الأزرق والأصفر، أو أزرق ثابت، أو أصفر ثابت.
- **زر «عرض»:** يفتح PDF وصور وWord وExcel والنصوص داخل الصفحة. أي ملف يُفتح مرة واحدة يبقى متاحاً بدون إنترنت.
- **مشاركة الصور:** زر بجانب الكورسات، ألبوم يتنقل بين الصور (أسهم وسحب ولوحة مصغرات)، ويظهر اسم المشارك. الصور تُصغَّر تلقائياً قبل الرفع.
- **أسماء الطلبة:** من لوحة الإدارة ← «إدارة أسماء الطلبة» (كل سطر اسم). يختار كل طالب اسمه مرة واحدة عند أول دخول (حتى للنسخ المثبّتة سابقاً)، وبعد اختياره يختفي الاسم من القائمة عند الجميع. من نفس النافذة يمكنك «إلغاء الاختيار» لأي اسم.
- **جولة الميزات:** تظهر لمرة واحدة عند أول فتح ويمكن تخطيها، وتُعاد من الإعدادات.
- ملفات `public/vendor/*` مكتبات العرض (PDF/Word/Excel) ويجب رفعها مع الموقع.
